# Теория вероятностей и математическая статистика

Учебные лабораторные работы (МИЭТ, группа ПМ-31): 12 лабораторных и одно проектное задание.
Каждая работа представлена двумя файлами: ноутбук `.ipynb` и его выгрузка `.html` (с сохранёнными результатами и графиками).

## Описание работ

Ниже описаны работы, содержимое которых проверено. Описание остальных (`LR1`–`LR4`, `LR6`, `LR9`–`LR12`) будет добавлено.

### LR5. Интервальные оценки

- Доверительные интервалы для математического ожидания (дисперсия неизвестна) и для дисперсии.
- Эксперимент на накрытие параметра: выборки объёма 1000 из N(3, 5²), доверительная вероятность 0,95. Параметр накрыли 95,9% интервалов на 49 выборках и 96,2% на 105 выборках.
- Зависимость границ интервалов от доверительной вероятности.
- Минимальный объём выборки для оценки вероятности успеха (p = 0,6, точность 2% от p): 6402 по формуле и по `statsmodels.stats.proportion.samplesize_confint_proportion`; в эксперименте оценка около 6800.
- Бутстреп-интервалы (1000 ресэмплов, 20 выборок) в сравнении с параметрическими.

### LR7. Критерии согласия

(в заголовке ноутбука работа названа «№6»)

- Гистограммы относительных частот, критерий согласия Пирсона (хи-квадрат).
- Проверка нормальности по критерию Шапиро-Уилка и Q-Q график после логарифмирования.
- Работа с реальными данными: результаты 5 тестов студентов. По гистограммам отобраны выборки, подходящие под нормальное, равномерное и показательное распределения (для показательного выборка преобразована отражением).
- Хи-квадрат для нормального распределения выборки A (p ≈ 0,008) и для показательного распределения выборки C (p ≈ 0,0007): в обоих случаях гипотеза отвергнута на уровне 0,1.
- Преобразование Бокса-Кокса (задание 4).

### LR8. Проверка гипотез о двух выборках

- Сравнение вероятностей получить не менее n баллов по двум дисциплинам (ОМА и МА) на реальных данных успеваемости: z-критерий для разности долей и критерий хи-квадрат, пороги n от 0,01 до 1,00 с шагом 0,01, уровень значимости 0,1, проверка применимости критериев. Определены диапазоны порогов, при которых данные подтверждают мнение «различий нет» или «различия есть».
- Критерий Фишера для сравнения дисперсий и t-критерии на сгенерированных нормальных выборках (задания 2-4), см. раздел «Известные проблемы».

### PZ. Проектное задание (вариант 5)

Моделирование стоимости акций двух компаний методом Монте-Карло.

- Недельная динамика за 4 года (208 недель), графики траекторий при разных значениях p.
- 1000 прогонов для p = 0,6: гистограммы итоговой стоимости, проверка нормальности критерием Шапиро-Уилка.
- Перебор p от 0,01 до 0,99 (по 100 прогонов на значение) для поиска p, при котором средние и медианы итоговой стоимости двух акций наиболее близки: диапазон p от 0,49 до 0,50.

## Стек

## Известные проблемы

Раздел будет удалён после исправлений.

- Генератор случайных чисел не зафиксирован (`seed` не задан): значения в симуляциях меняются при каждом запуске.
- Исходные данные (`Data_*.xlsx`) в репозиторий не включены (материалы курса), поэтому ноутбуки без них не запускаются; результаты можно посмотреть в `.html`-версиях.
- LR5: при бутстрепе ресэмплы объёма 200 берутся из выборок объёма 500, поэтому бутстреп-интервалы получаются шире параметрических. Корректное сравнение требует ресэмплов объёма, равного размеру выборки.
- LR7: в одной из проверок критическое значение рассчитано для неверного числа степеней свободы (`chi2(6)` вместо `chi2(3)`); p-значение рассчитано верно. В нескольких формулировках выводов вместо нужного распределения указано «равномерное».
- LR8, задание 1: пропуски в исходных данных заменены нулями, что влияет на оценки долей при малых порогах.
- LR8, задания 2-4: выборки C' и D' сгенерированы с параметрами выборок A и B, а в статистике Уэлча использована одна и та же оценка дисперсии для обеих выборок. Результаты этих заданий требуют пересчёта.
