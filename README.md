## 📂 Структура репозитория

### 📌 Task 1: Расчет заработной платы и графический анализ
*Файл: `Task_1_Grechishkin_Denis_PM_11.xlsx`*

1.  **Лист "Таблица"**:
    *   Создана модель расчета ЗП для сотрудников разных отделов (Цех, Бухгалтерия, Склад).
    *   Реализована логика начисления премий через вложенные `ЕСЛИ` с градацией от 5% до 10% в зависимости от оклада.
    *   Автоматический расчет НДФЛ (34,2% в модели) и суммы к выдаче.
    *   Итоговая статистика: средний доход, макс/мин оклад, количество сотрудников цеха.
    *   Двойная сортировка данных (по ФИО и сумме к выдаче).

2.  **Лист "График"**:
    *   Построены графики функций $y = 5x^3 - 4$ и $z = 80x^2 - 300$.
    *   Найдены корни уравнений и точки пересечения графиков с помощью инструмента **«Подбор параметра»**.
    *   Визуализированы координаты пересечения для проверки точности расчетов.

3.  **Лист "Подбор параметра"**:
    *   Решена экономическая задача сравнения стоимости поездки на авто vs ЖД (Москва-Екатеринбург, Москва-Сочи).
    *   Найдены критические значения: цена билета, расход бензина и количество пассажиров, при которых затраты на авто и поезд становятся равными.

### 📌 Task 2: Анализ данных заказов (Сводные таблицы)
*Файл: `Task_2_Grechishkin_Denis_PM_11.xlsx`*

1.  **Исходные данные**:
    *   База из 30+ заказов на IT-услуги (разработка, тестирование, внедрение ПО).
    *   Данные включают: ID заказа, дату, студента-исполнителя, тип работы, город заказчика, сумму.

2.  **Сводные отчеты (Pivot Tables)**:
    *   **Отчет 1**: Агрегация сумм выплат по каждому студенту в разрезе видов работ. Выявлены наиболее прибыльные направления для каждого исполнителя.
    *   **Отчет 2**: Общая статистика по видам работ (какой тип задач приносит компании наибольший доход).
    *   **Отчет 3**: Географический анализ заказов по городам (Краснодар, Саратов, Иваново, Волгоград, Астрахань).
    *   Использованы фильтры и группировка дат для анализа сезонности спроса.

## 🎓 Выводы и результаты курса

За время прохождения дисциплины были достигнуты следующие результаты:

1.  **Автоматизация рутинных расчетов**: Научился заменять ручные вычисления динамическими формулами Excel, что снижает риск ошибок и ускоряет обработку больших массивов данных (например, расчет ЗП для всего штата одной формулой).
2.  **Навык работы с большими данными**: Освоил создание и настройку сводных таблиц для быстрого ответа на бизнес-вопросы (кто самый эффективный сотрудник? какой город самый заказчик?).
3.  **Решение оптимизационных задач**: Понял, как использовать инструмент «Подбор параметра» для обратного инжиниринга задач (поиск входных данных для получения нужного результата).
4.  **Визуальная коммуникация**: Научился представлять числовые данные в виде понятных графиков, выделяя ключевые точки (пересечения, экстремумы) для принятия решений.
5.  **Подготовка к Python**: Логика обработки данных в Excel (фильтрация, группировка, условные вычисления) стала фундаментом для дальнейшего изучения библиотек `Pandas` и `NumPy`, так как принципы манипуляции датафреймами аналогичны работе с таблицами Excel.
