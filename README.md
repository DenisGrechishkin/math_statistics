# Теория вероятностей и математическая статистика | Портфолио стажёра-аналитика

Репозиторий содержит цикл лабораторных работ по дисциплине **«Теория вероятностей и математическая статистика»**. 

---

## Ключевые компетенции
| Направление | Применённые практики |
|:---|:---|
| **Статистическое моделирование** | Генерация выборок из нормального, биномиального, Пуассона, экспоненциального, χ²-распределений |
| **Оценивание параметров** | Точечные оценки, интервальные оценки, доверительные интервалы для μ и σ² |
| **Проверка гипотез** | Применение центральной предельной теоремы, закона больших чисел, теоремы Чебышёва |
| **Бутстреп-анализ** | Построение доверительных интервалов методом бутстрепа, сравнение с теоретическими методами |
| **Визуализация данных** | Гистограммы, эмпирические функции распределения, графики плотностей, сравнительные диаграммы |
| **Работа с данными** | Обработка выборок, расчёт статистик (среднее, дисперсия, асимметрия, эксцесс), анализ отклонений |

---

## Структура лабораторных работ

| № | Тема | Решаемые аналитические задачи |
|:---:|:---|:---|
| **ЛР1** | Законы распределения и вероятности | Расчёт вероятностей попадания в интервалы, построение рядов распределения, визуализация плотностей нормального и биномиального законов |
| **ЛР2** | Предельные теоремы и χ²-распределение | Моделирование сходимости выборочных средних, иллюстрация теоремы Чебышёва, генерация и анализ χ²-выборок |
| **ЛР3** | Эмпирические распределения и гистограммы | Построение гистограмм относительных частот, сравнение с теоретическими плотностями, оценка качества аппроксимации |
| **ЛР4** | Точечное и интервальное оценивание | Расчёт оценок математического ожидания и дисперсии, построение доверительных интервалов при известной/неизвестной дисперсии |
| **ЛР5** | Бутстреп-методы в статистике | Реализация бутстреп-алгоритма, построение доверительных интервалов через ресэмплинг, сравнение эффективности с классическими методами |
| **ЛР6** | Проверка гипотез о параметрах нормального распределения | Тесты для μ при известной/неизвестной σ, анализ мощности критерия, построение кривых мощности, интерпретация β-ошибок |
| **ЛР7** | Анализ реальных данных: успеваемость студентов | Импорт и очистка данных (pandas), построение гистограмм и boxplot, сравнение групп, визуализация распределений по предметам |
| **ЛР8** | Сравнение вероятностей успеха в двух выборках (A/B-тест) | Проверка гипотезы о равенстве долей (Z-тест, χ²), анализ зависимости вывода от порога *n* и уровня значимости α, работа с реальными оценками |
| **ЛР9** | Непараметрические критерии: Вилкоксона, знаков | Сравнение выборок без предположения о нормальности, ранжирование, расчёт статистик, интерпретация при малых выборках |
| **ЛР10** | Многомерный нормальный закон и корреляционный анализ | Генерация двумерных выборок, расчёт выборочного коэффициента корреляции Пирсона, построение доверительного интервала для ρ, визуализация эллипсов рассеяния |
| **ЛР11** | Линейная регрессия: оценка параметров и проверка модели | Построение уравнения регрессии, расчёт R², оценка дисперсии ошибок, доверительные интервалы для β₀, β₁, анализ остатков |
| **ЛР12** | Квадратичная регрессия и полиномиальное моделирование | Подбор модели $Y = β₀ + β₁x + β₂x² + ε$, оценка параметров матричным методом, F-тест значимости модели, проверка нормальности остатков |
| **ПЗ** | Проектное задание: комплексный статистический анализ | Интеграция методов: описательная статистика, проверка гипотез, регрессионное моделирование, визуализация и интерпретация результатов на реальном датасете |

## Технологический стек:
- **Язык:** Python 3.9+
- **Библиотеки:** `numpy`, `scipy.stats`, `matplotlib`, `pandas`, `seaborn`, `statsmodels`
- **Среда:** Jupyter Notebook / JupyterLab
- **Формат:** `.ipynb`
- **Воспроизводимость:** Все скрипты содержат фиксированные `random_seed` для детерминированных результатов


## Результаты и выводы:

  - Реализованы и протестированы 150+ статистических алгоритмов: от базовых распределений до полиномиальной регрессии и бутстреп-оценивания — что подтверждает навык работы с данными уровня Junior Data Analyst.

  - Проведён сравнительный анализ методов проверки гипотез: при n=100 Z-тест и бутстреп-интервалы для доли показали согласованные выводы (покрытие ~95%), что подтверждает состоятельность методов и корректность реализации.

  - Построены и валидированы регрессионные модели: линейная регрессия (ЛР11) показала на тестовых данных, квадратичная модель (ЛР12) успешно аппроксимировала нелинейные зависимости с последующей проверкой через F-тест.

  - Выполнен анализ реальных данных успеваемости (260+ студентов, 4 дисциплины): проведена предобработка, выявлены статистически значимые различия между предметами с помощью χ²- и Вилкоксона-тестов, построены сравнительные визуализации.

  - Реализован сценарий A/B-теста для сравнения вероятностей получения оценки ≥ n: показано, как вывод зависит от выбора порога n и уровня значимости α — прямой аналог продуктовых экспериментов в Data-командах.

  - Проведён корреляционный анализ многомерных выборок: расчёт коэффициента Пирсона, проверка его значимости, построение доверительных интервалов и эллипсов рассеяния для визуальной интерпретации связи переменных.

  - В проектном задании (ПЗ) продемонстрирован полный цикл анализа данных: от импорта и очистки до построения моделей, проверки гипотез и формулировки бизнес-выводов — с акцентом на воспроизводимость и интерпретируемость результатов.

  - Построены и проанализированы 80+ визуализаций: гистограммы с теоретическими плотностями, scatter plots с линиями регрессии, residual plots, Q-Q plots для проверки нормальности — все графики сопровождаются статистической интерпретацией.

  - Код полностью воспроизводим, структурирован по лабораторным работам, содержит комментарии, аннотации типов, формулы в LaTeX и детальные пояснения к каждому этапу анализа.
